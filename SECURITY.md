# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue. Use
[GitHub's private vulnerability reporting form](https://github.com/palewire/django-bakery/security/advisories/new)
when it is available. Otherwise, contact a project maintainer privately
through their GitHub profile and include:

- a description of the vulnerability and its impact;
- the affected versions and configuration;
- reproducible steps or a proof of concept; and
- a suggested fix, if you have one.

Please allow maintainers reasonable time to investigate and release a fix
before making the vulnerability public.
